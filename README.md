PirateCast Card

PirateCast Card — самостоятельная Lovelace-карточка для Home Assistant, показывающая изменение атмосферного давления на горизонтальной шкале.

Карточка устанавливается отдельно от интеграции PirateCast.

Возможности

- Горизонтальная шкала изменения давления.
- Шесть погодных значков.
- Маркер текущего значения.
- Стрелка тенденции: влево при снижении давления и вправо при повышении.
- Настраиваемые сенсор, заголовок и диапазон шкалы.

Требования

- Home Assistant с поддержкой пользовательских Lovelace-карточек.
- Сенсор с числовым значением изменения давления в мм рт. ст.

Для создания сенсоров можно установить интеграцию "PirateCast" (https://github.com/devil2012devil/PirateCast). Карточка может использовать и другой сенсор, если он возвращает изменение давления в тех же единицах.

Установка через HACS

1. Откройте HACS.

2. Перейдите в раздел пользовательских репозиториев.

3. Добавьте "https://github.com/devil2012devil/PirateCast-Card".

4. Выберите категорию Dashboard.

5. Установите PirateCast Card.

6. Если HACS не добавил ресурс автоматически, откройте Настройки → Панели управления → Ресурсы.

7. Добавьте ресурс:
   
   - URL: "/hacsfiles/piratecast-card/piratecast-card.js"
   - Тип: JavaScript Module

8. Обновите страницу Home Assistant.

Если ресурс не загружается, проверьте его URL и каталог, созданный HACS. При необходимости перезапустите Home Assistant и обновите страницу с очисткой кэша браузера.

Настройка карточки

Добавьте карточку вручную в YAML-редакторе панели управления:

type: custom:piratecast-card
entity: sensor.piratecast_pressure_change_3h
title: Изменение давления за 3 часа
min: -4
max: 4

Параметры:

Параметр| Назначение
"type"| Тип карточки; не изменяется
"entity"| ID сенсора изменения давления
"title"| Заголовок карточки
"min"| Нижняя граница шкалы
"max"| Верхняя граница шкалы

Для стандартного отображения используйте симметричный диапазон, например от "-4" до "4".

Как читать шкалу

- Отрицательное значение означает снижение давления за выбранный интервал.
- Положительное значение означает повышение давления.
- При значении около нуля стрелка скрывается.
- Маркер показывает числовое значение на шкале.
- Если состояние сенсора отсутствует, карточка выводит «Нет данных».

Значения за пределами диапазона ограничиваются положением крайней отметки шкалы. Отображаемое числовое значение при этом сохраняется.

Устранение неполадок

Карточка не найдена

Проверьте, что ресурс JavaScript добавлен как JavaScript Module, а в YAML указан тип "custom:piratecast-card".

Вместо значения отображается «Нет данных»

Убедитесь, что выбранная сущность существует и имеет числовое состояние.

Стрелка не отображается

Стрелка скрывается, когда значение находится между "-0.01" и "+0.01". Если значение выходит за этот диапазон, обновите страницу Home Assistant и проверьте, что загружена актуальная версия JavaScript.
